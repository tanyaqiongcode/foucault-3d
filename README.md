# 福柯 · 全景敞视 — 3D 文献站

以全景敞视监狱（Panopticon）为核心意象的福柯主题 3D 站：环形监舍 ×2 层 · 24 室 ·
中心瞭望塔 · 逆光单向可见。凝视刻意不可视化——被囚者无法确知此刻是否被看，
塔灯的偶发明暗即此不可确知。

姊妹站：[华夏边缘 · Huaxia Frontier](https://tanyaqiongcode.github.io/huaxia-frontiers-3d/)

## 技术

- three.js r128（MIT）· 零外部依赖（three.min.js 本地内联）
- 画质四档（自动/典藏/均衡/轻量，DPR × 粒子密度联动）· 按需渲染
- 键盘：←→ 微调 · P 暂停 · Tab 可达全部控件 · 空白处 Ctrl/⌘+滚轮缩放（正文上方保留浏览器网页缩放） · 滚动换节=镜头绕监狱公转
